Restaurant Time Clock

Client project, 2026

Staff tap an NFC tag with their own Android phone to clock in and out, so the restaurant no longer needs a shared kiosk. Shifts close themselves, and payroll reports arrive in the owner's inbox every month.

Built with MongoDB, Express, React, Node.js, TypeScript, Web NFC, PWA, AWS EC2, Nginx, PM2, GitHub Actions

What it does

  • Clocks staff in and out with Web NFC on their own devices, installed as a progressive web app.
  • Clocks staff out automatically when they leave the geofence, using location checks every 45 seconds. A server-side timeout closes any shift that is still open, so every shift gets closed.
  • Secures the REST API with JWT for admins and PINs for employees. It calculates pay and flags incomplete shifts as they happen.
  • Builds a multi-sheet Excel payroll report each month (summary, daily detail and raw events) and emails it automatically.

How it runs

  • Runs on AWS EC2, with PM2 for zero-downtime restarts and Nginx as a reverse proxy serving it over HTTPS.
  • A systemctl service brings PM2 and the app back after a server reboot and gives clean start, stop and restart control.
  • GitHub Actions tests every change and deploys it to EC2, which removes manual release steps.
